# Spec: 画面の言語 — 中国語（簡体字）・韓国語

**ID**: 35
**Date**: 2026-10-31
**Status**: **Draft** — rev0（[spec 31](31_ui-language.md) rev1 で分けた。D1〜D4 の裁定待ち。spec 31・34 の後に進める）
**Branch**: 切らない（Phase 単位で main へ直接コミット）。フォーク元の訳（`locales/`）とデスクトップの訳（`lib/desktop/locales/`）・書き出しのフォント（`crates/`）でコミットを分ける

## Goal

spec 31・34 の仕組みに、利用者の言（2026-10-30）「英語と中国語と韓国語と日本語」の残りの 2 つを載せる。訳を作り、4 つの言語で画面がはみ出さず重ならないことを確かめる。

## 現況（2026-10-31、spec 31 の査読で確かめた）

- **書き出しの同梱フォントに韓国語と簡体字が無い**: `crates/lorelei_core/fonts/NotoSansJP-Regular.ttf` はハングルの音節 11,172 字のうち 0 字、簡体字の「们 这 说 实 简」も無い（fontTools で確かめた）。
  `fonts.rs` は同梱フォントだけを読み、システムのフォントは読まない。韓国語・中国語のラベルの図は PNG・PDF（と MCP の `render` の preview）で字が欠けるはず（推測。描いては確かめていない）。
  これは画面の言語を切り替えなくても、今すでに起きうる（AI が韓国語のラベルの図を書いた時）
- 韓国語の助詞は名詞の終わりの音で変わる（`을/를`・`이/가`）。spec 31 D6 で、名前を差し込む文はこの spec で `을(를)` の形にすると決めた
- 言語の対応表（`zh-CN`・`zh-SG`・ただの `zh` → `zh-Hans`、繁体字 → 英語、`ko*` → `ko`）は spec 31 D4 で決めてある

## 決めること

### D1. 訳の作り方と確かめ方

- **推奨**: 英語の訳を元に、こちらで中国語・韓国語の訳を作る。**母語の人が確かめていない**ことを README（英語・日本語）に書き、直しを Issues で受ける（CONTRIBUTING に手順）

### D2. 言語の名と一覧へ足す時

- **推奨**: 简体中文・한국어。訳が揃い、キーの組のテスト（spec 31 D10）が緑になった時に言語の一覧へ足す

### D3. 見た目の確かめ

- **推奨**: spec 27 の台本（`scripts/ui-style-snapshot.mjs`）で、4 つの言語の全部の場面を裏の Edge で撮り、はみ出し・重なりを見て直す。台本の要素の選び方を言語に依らない形（testid かキーの引き当て）に替える

### D4. 書き出しのフォント

- **推奨: この spec で扱う**（中国語・韓国語の利用者が図を書き出すと字が欠けるので、Goal に直に響く）。Noto Sans KR・Noto Sans SC を `scripts/build-fonts.py` と同じ形で切り出して同梱し、`fonts.rs` の代わりのフォントに足す。配布物の大きさの増え方を P0 で測る
- 案: 別の spec にする（画面の言語と独立に、今すでに起きうる不具合なので）

## 受け入れ条件（rev0）

1. Web 版とデスクトップで、中国語（簡体字）・韓国語に切り替えられる。キーの組のテストが 4 つの言語で緑
2. 4 つの言語の台本の全部の場面で、文字が部品からはみ出さない・重ならない
3. 韓国語の名前を差し込む文が `을(를)` の形
4. （D4 を採るなら）韓国語・簡体字のラベルの図を PNG・PDF に書き出して字が欠けない
5. README（英語・日本語）に言語の切り替えと訳の確かめの状態
6. 配布ビルドで利用者が確かめる

## Phase

- **P0**: フォントの大きさ（D4）・台本の選び方の替え方

- **P2**: フォント（D4）
- **P3**: 配布ビルドで利用者が確かめる。README・ライブデモ
